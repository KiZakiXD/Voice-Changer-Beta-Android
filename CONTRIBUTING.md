Cara Berkontribusi

Terima kasih sudah mau membantu proyek ini. Proyek ini masih dalam tahap pengembangan beta, jadi masukan dan laporan bug sangat membantu.

Cara ikut kontribusi

Fork repo ini, lalu buat branch baru dari main untuk perubahanmu. Buat perubahan yang kecil dan jelas, satu branch untuk satu hal. Setelah selesai, buka pull request ke branch main dan tulis dengan singkat apa yang diubah dan kenapa.

Cara lapor bug

Buka tab Issues di repo ini, lalu buat issue baru. Tuliskan langkah-langkah untuk mengulang bugnya, apa yang terjadi, dan apa yang seharusnya terjadi. Kalau bisa, sertakan juga jenis HP dan versi Android yang dipakai, serta preset suara yang sedang aktif saat bug terjadi.

Hal yang perlu diperhatikan

Jangan mengubah file APK atau file utama tanpa diskusi dulu di issue. Jaga perubahan tetap sederhana dan mudah dibaca. Kalau ragu, tanyakan dulu lewat issue sebelum mulai mengerjakan perubahan besar.
